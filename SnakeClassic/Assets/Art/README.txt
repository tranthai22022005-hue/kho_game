Map ký tự:
# = tường/vật cản cố định
. = ô trống
S = đầu rắn
s = thân rắn ban đầu
F = thức ăn ban đầu

Unity import gợi ý:
- Texture Type: Sprite (2D and UI)
- Pixels Per Unit: 128 cho sprite ô đơn
- Filter Mode: Point hoặc Bilinear đều được; Point sẽ nét kiểu pixel.
- Sprite Mode: Single
