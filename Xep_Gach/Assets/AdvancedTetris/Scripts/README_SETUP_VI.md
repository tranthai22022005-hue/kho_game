# Advanced Tetris Mobile - Unity Starter Kit

Bộ tài nguyên này gồm:
- PNG block I/O/T/S/Z/J/L, ghost block, button mobile, background, board panel.
- WAV hiệu ứng và nhạc chiptune gốc.
- Script C# cho core game: bảng 10x20, 7-bag random, wall kick, hold, next queue, ghost, score, combo, level, soft drop, hard drop, T-spin cơ bản.
- Hướng dẫn lắp trong Unity.

Lưu ý: Nhạc trong gói là bản gốc phong cách chiptune, không phải bản thu Tetris thương mại.
