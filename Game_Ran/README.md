# Bắn Bóng 2D - Fantasy Lake

Project Unity 2D dùng ảnh trong `Version_A_FantasyLake.zip`.

## Cách chạy
1. Mở Unity Hub.
2. Add project from disk vào thư mục này.
3. Mở `Assets/Scenes/MainScene.unity`.
4. Bấm Play.

## Điều khiển
- Trái / A hoặc nút trái: xoay hướng bắn sang trái.
- Phải / D hoặc nút phải: xoay hướng bắn sang phải.
- Xuống / S / Space hoặc nút bắn: bắn bóng.
- Lên / W hoặc nút xoay: đổi bóng hiện tại với bóng NEXT.
- Pause: tạm dừng.

## Tính năng
- Menu, Game, Pause, Setting, Game Over.
- Score, Best Score.
- Bóng nhiều màu, preview bóng tiếp theo.
- Cụm 3 bóng cùng màu sẽ nổ.
- Bóng rời khỏi trần sẽ rơi/xóa.
- Âm thanh bắn, nổ, click, game over, win và nhạc nền.
- New Input System + Canvas 2D.
